# Sherif Ayo | Developer Portfolio

My personal developer portfolio, built with React and Vite. It showcases my skills and projects in a clean, responsive single-page layout.

**Live site:** https://my-portfolio-psi-ten-22.vercel.app

## Features

- Responsive design that works on phones, tablets and desktops
- Smooth-scrolling navigation between sections
- Sections for About, Skills, Projects and Contact
- All content (bio, skills, projects, contact details) is stored in a single data file, so updating the site means editing one place

## Built With

- [React](https://react.dev/)
- [Vite](https://vite.dev/)
- CSS (custom styles, CSS variables, Flexbox and Grid)
- ESLint
- Deployed on [Vercel](https://vercel.com/)

## Project Structure

```
src/
  components/   Navbar, Hero, About, Skills, Projects, Contact, Footer
  data/         profile.js (all site content)
  App.jsx
  index.css
```

## Run It Locally

1. Clone the repository
   ```bash
   git clone https://github.com/S-Ayo1/my-portfolio.git
   cd my-portfolio
   ```
2. Install dependencies
   ```bash
   npm install
   ```
3. Start the development server
   ```bash
   npm run dev
   ```
4. Open the local address shown in the terminal (usually `http://localhost:5173`).
